# 使用指南

## 第一次启动

应用现名 Scrylet，原名 Snap-Solver。Node 首次启动会将旧 `Snap-Solver` 数据只读迁移到 `Scrylet` 目录，旧数据保留，应用 ID 不变。

Windows x64 用户可直接运行 `dist/releases/2.0.0-dev.7/` 中的 `Scrylet-…-Setup.exe`，按向导选择安装位置；完成后从桌面或开始菜单启动。安装版已包含 Electron、Node 服务和手机页面，无需安装开发工具。当前安装包未签名。

从源码开发时使用以下步骤：

安装 Node.js 22.12+ 后，在项目目录运行：

```sh
npm ci
npm run setup
npm start
```

`npm run setup` 只准备 Node 服务 / 手机页面和预编译输入资源；`npm start` 默认进入新版。若存在旧库，先退出旧版，首次启动会自动显示迁移进度并导入到新 `Scrylet` 目录，不删除原数据。完全隔离的开发目录使用 `npm run start:node -- --data <绝对路径>`。旧版源码与断言保存于归档，旧数据导入及回退导出保留；详见 [M5 收尾](node-service-finalization.md)。

## 配对手机

让手机和电脑连接同一局域网。看到桌面状态“可以连接手机”后，用手机相机扫描二维码。

无法扫描时，展开电脑上的“手动连接与网络设置”：在手机浏览器打开显示的地址，再输入六位连接码。多个网卡时可切换地址。公司或访客 Wi-Fi 可能隔离设备，可以改用个人热点；Windows 防火墙需要允许专用网络访问。

如果手动输入 IP 能打开，而扫码提示无法访问，检查这里选择的网卡是否与手动成功的 IP 一致。新版默认优先普通局域网地址，避免优先选中 Meta / Clash 等虚拟网卡。手动选择会被记住，切换后二维码立即更新；请扫描新二维码。

macOS 需要在系统设置的“隐私与安全性 → 屏幕与系统音频录制”中允许开发态的 Electron，然后重启 App。手机使用时不需要屏幕录制权限。

## 添加模型

在电脑 App 左侧打开“模型服务”，选择一家服务，填写自己的 API Key。型号和中转地址位于展开项里。保存只配置连接，不会发送模型请求；服务是否可用以实际账户权限为准。手机端只选择已连接的模型。

已有密钥不会在简易设置表单回显。留空保存会保留原密钥；填写新密钥会替换。

## 截屏与提问

在电脑操作时，先在电脑连接模型，再让手机扫码并保持聊天页在前台即可。点击电脑上的“截屏并发送”或按 `Ctrl+Alt+S`，整屏图片会连同默认提示词自动提交给当前模型。也可从托盘触发。

区域截图在电脑上完成：按住左上角 1.2 秒后松开，5 秒内开始按住右下角 1.2 秒，松开后自动发送。两个角需在同一显示器，拖动不算长按；超时或选区时按 `Esc` 都会取消。也可以点击“区域截屏”或按 `Ctrl+Alt+A` 开始选区。

电脑“截图操作与默认提示词”中可以修改快捷键、鼠标按键、两种时长和提示词，也能按需开启双击截全屏。鼠标手势支持 Windows x64 与 macOS arm64 / x64；Mac 首次启用需允许输入监控。手机有草稿、回答生成中或位于后台时，暂不能发送，不会覆盖草稿或重复提交。

截图始终静默：不播放声音，不显示选区框、倒计时、结果弹窗或系统通知，也不自动弹出或聚焦主窗口。旧版开启过的提示设置会被忽略。手机端通知声与振动保持关闭，自动朗读默认关闭；截图和自动发送照常执行，异常原因可在电脑操作日志查看。

以下是仍可在手机上使用的手动收集方式：

点击“截屏”直接添加整屏图片，重复点击就继续添加。需要裁剪时，点“框选”，拖动选区边角后点“添加选区到对话”。有多台显示器时，可在截图区上方切换，也可在框选页切换。“手机图片”用于添加手机里的图片；密钥在电脑 App 的“模型服务”中管理，输入框底部的型号名称用于切换本次回答的模型。

图片按添加顺序编号，新对话中以大图或网格展示；已有回答或可用高度较小时收成横向缩略图，可左右滑动查看更多。点开图片可左右翻看、放大；支持单张删除和一键清空，10 秒内点“撤销”可恢复到队列末尾。每次最多 12 张。

图片都先留在输入框中，可以补充文字。点击发送后，图片与问题才会一起传给模型。题干、图表、选项分开显示时，可以分多次截屏并一次提问。

手机顶部会明确显示“电脑已连接”；断开、暂停或需要截屏权限时显示对应文字，点击状态可以查看处理提示。

回答支持公式、代码块与继续追问。模型菜单可以在同一对话中切换服务；新模型会接收当前对话的上下文。

## 自动朗读回答

手机聊天页顶部的“朗读关”默认关闭。点一下变成“朗读开”，之后每轮回答生成完成都会自动朗读，包括电脑截图自动发送后的回答，不需要逐条点击。朗读时可点输入区中的“停止朗读”停下本次；点顶部开关关闭后立即停止，后续回答恢复静默。

开关仅记在这部手机的当前浏览器，不影响电脑或其他设备。使用系统 / 浏览器的语音合成，无需另填 API Key。长回答会分段朗读，Markdown 的格式标记不会念出，标题、正文、公式文字和代码内容保留。重新加载和打开历史不会自动重读过去的回答；切换对话或切到后台会停止当前朗读。

浏览器刷新后可能要求首次轻触页面以恢复语音会话，之后可继续自动播放。请保持手机聊天页在前台；锁屏或后台播放受手机系统限制。不支持语音合成时开关不可用，语音失败会显示行内说明。

### 选择更舒服的声音

点击输入区“添加图片”旁的“声音”，打开音色与语速面板。默认“自动优选”会先匹配中文地区，再优先使用系统音色信息中带高品质、增强或自然标识的音色；也可以手动选择喜欢的声音。语速默认 0.95×，可在 0.8×～1.2× 调节。短句会按段落交给语音引擎处理停顿。

点“试听声音”可直接听一个示例，试听不会打开自动朗读；再点一次或关闭面板会停止试听。选项立即保存在当前浏览器，下一轮回答开始使用。打开面板不会自动发声，也不会补播旧回答。

页面只能列出浏览器当前能用的系统音色，无法保证每部手机都有相同的高品质声音。列表为空或已选音色暂不可用时，会回退到自动 / 系统默认声音，并在声音重新可用后恢复原选择。想增加音色，可在手机系统的语音设置中下载中文声音；例如 [Apple 官方说明](https://support.apple.com/en-ie/111798) 介绍了增强声音的下载方法。无需填写额外的语音服务密钥。

## 运行与数据

电脑窗口中展开“操作日志与缓存”，可查看最近操作并筛选异常。日志只记录操作类型和必要的状态，不包含截图内容、聊天正文、密钥或默认提示词。

“清除缓存”只清理页面与代码缓存，可能在继续使用时重新生成少量缓存；不会删除聊天、图片附件、配对、密钥、提示词设置或日志。清理过程与结果显示在该面板内，不会开启截图提示。

关闭电脑窗口后仍在菜单栏 / 托盘运行，从托盘可以重新打开或退出。退出后手机无法连接。

在电脑“已配对设备”里点“取消配对”，会立即撤销手机访问；“换一个码”不会撤销已配对手机。“暂停手机访问”只是暂时断开手机，不等于停止已开始的生成；需要停止时请使用聊天中的“停止回答”，或退出整个 App。

手机之间共享这台电脑的聊天与设置。请只配对自己的设备，并仅在可信局域网使用。截图与聊天记录保存在电脑，发送的问题会按所选服务传到云端模型。

旧版中转地址也会导入。如果该中转仅支持厂商原生协议，需要在“模型与服务地址”里改成兼容的新接口地址：OpenAI 使用 Responses，其余内置服务使用 Chat Completions 兼容接口。
